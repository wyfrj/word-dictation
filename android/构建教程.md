# 安卓 APK 详细构建教程

## 📋 前置准备

### 1. 注册 GitHub 账号
访问 https://github.com/join 注册账号(如果还没有)

### 2. 安装 Git
下载并安装 Git: https://git-scm.com/downloads

### 3. 配置 Git (可选但推荐)
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

## 🚀 步骤 1: 创建 GitHub 仓库

### 方法 A: 通过网页创建
1. 登录 GitHub
2. 点击右上角 `+` → `New repository`
3. 填写仓库信息:
   - **Repository name**: `word-dictation` (或其他你喜欢的名字)
   - **Description**: 英语单词听写软件
   - **Public/Private**: 选择 Public(免费) 或 Private
   - **Initialize this repository with a README**: ✅ 勾选
4. 点击 `Create repository`

### 方法 B: 通过命令行创建
```bash
# 在本地项目目录执行
cd "C:\Users\wyf\Desktop\新建文件夹 (2)\新建文件夹 (5)"

# 初始化 Git
git init

# 添加所有文件
git add .

# 提交
git commit -m "Initial commit: 英语单词听写软件"

# 关联远程仓库(替换你的用户名)
git remote add origin https://github.com/你的用户名/word-dictation.git

# 推送到 GitHub
git branch -M main
git push -u origin main
```


1. 进入你的 GitHub 仓库
2. 点击 `Actions` 标签页

## 🚀 步骤 4: 触发自动构建

### 方法 A: 推送触发(推荐)
```bash
# 修改任意文件后推送,会自动触发构建
git add .
git commit -m "触发构建"
git push
```

### 方法 B: 手动触发
1. 进入 GitHub 仓库的 `Actions` 标签页
2. 点击左侧的 `Build Android APK`
3. 点击右上角的 `Run workflow`
4. 选择分支(通常是 `main`)
5. 点击 `Run workflow` 按钮

---

## 🚀 步骤 5: 等待构建完成

### 构建状态说明
| 状态 | 含义 |
|------|------|
| 🟡 黄色圆点 | 构建中 |
| 🟢 绿色对勾 | 构建成功 |
| 🔴 红色叉号 | 构建失败 |

### 构建耗时
- **首次构建**: 10-30 分钟(需要下载 Android SDK/NDK)
- **后续构建**: 5-10 分钟(使用缓存)

### 查看构建日志
1. 点击进入 workflow run
2. 点击 `build` job
3. 展开各个步骤查看详细日志

---

## 🚀 步骤 6: 下载 APK

### 下载步骤
1. 进入成功的 workflow run 页面
2. 在页面底部找到 `Artifacts` 部分
3. 点击 `word-dictation-apk` 下载
4. 解压后得到 `app-debug.apk`

### 安装到安卓手机
```bash
# 方法 1: 直接传输到手机安装
# 将 APK 文件通过微信、QQ、数据线等方式传输到手机
# 在手机上点击安装(可能需要允许"未知来源"安装)

# 方法 2: 使用 adb 安装(需要安装 Android SDK Platform Tools)
adb install app-debug.apk
```

## 🔧 常见问题

### Q1: 构建失败怎么办?
**A:** 查看构建日志,常见原因:
- 网络问题导致下载依赖失败
- buildozer.spec 配置错误
- GitHub Actions 配置文件路径错误

### Q2: 如何修改应用名称?
**A:** 修改 `android/buildozer.spec` 中的 `title` 字段:
```ini
[app]
title = 你的应用名称
```

### Q3: 如何修改包名?
**A:** 修改 `android/buildozer.spec` 中的 `package.name` 和 `package.domain`:
```ini
[app]
package.name = yourappname
package.domain = org.yourname
```

### Q4: 如何添加新权限?
**A:** 修改 `android/buildozer.spec` 中的 `android.permissions`:
```ini
[app]
android.permissions = INTERNET, WRITE_EXTERNAL_STORAGE
```

### Q5: 如何清理构建缓存?
**A:** 在 GitHub Actions 页面,点击 `Actions` → `Build Android APK` → 点击右上角 `Clear cache`
